# Convex Embedded

`@estifanos-sh/convex-embedded` is an independent local-first runtime for Convex. It keeps the application schema,
authorization, and Convex functions in ordinary Convex code while maintaining a durable device
projection and replication metadata.

For setup, platform requirements, and migration guidance, see the repository README:
https://github.com/estifanos-sh/convex-embedded#readme

Install the package directly; its public imports are all under
`@estifanos-sh/convex-embedded`.
