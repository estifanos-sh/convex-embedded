# Convex Embedded

`@convex-dev/embedded` is Convex's local-first runtime. It keeps the application schema,
authorization, and Convex functions in ordinary Convex code while maintaining a durable device
projection and replication metadata.

For setup, platform requirements, and migration guidance, see the repository README:
https://github.com/get-convex/embedded#readme

Test releases published before the official Convex package launch use
`@robelest/convex-embedded` and preserve the same public import paths through an npm alias.
